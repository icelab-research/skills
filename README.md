# skills

Reusable agent skills published by Ice Lab Research.

## available skills

| Skill | Purpose |
|---|---|
| [`dialogue-reels-editing`](dialogue-reels-editing/SKILL.md) | Edit multi-speaker podcast and interview footage into synced, captioned, studio-polished short-form video. |
| [`randomly-distributed-video-brand`](randomly-distributed-video-brand/SKILL.md) | Apply the Randomly Distributed retro-technical identity to covers, captions, thumbnails, and motion graphics. |

Read [`RESOLVER.md`](RESOLVER.md) when both skills may apply. The machine-readable package index is in [`manifest.json`](manifest.json).

## install

Copy or symlink an individual skill directory into your agent's global skills directory. Keep the directory structure intact because each `SKILL.md` references local assets, templates, scripts, and guidance.
